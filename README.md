# Yasser Web | نظام ياسر ويب 🚀
A lightweight, modern web-based inventory and debt management system built with Python and Streamlit to simplify daily shop operations.

نظام ويب بسيط وسريع لإدارة المبيعات، المخازن، ودفتر الديون للمحلات التجارية، مصمم خصيصاً بـ Python و Streamlit ليكون سهلاً وخفيفاً على أصحاب المشاريع.

---

### ✨ Features | المميزات الرئيسية:
- 📦 **Inventory & Stock Management:** جرد كامل للمخزن ومتابعة المواد بسهولة.
- 💳 **Debt & Customer Tracking:** إدارة حسابات الزبائن والديون بدقة.
- ⚡ **Streamlit Powered:** واجهة سريعة وخفيفة وتعمل مباشرة على المتصفح.
